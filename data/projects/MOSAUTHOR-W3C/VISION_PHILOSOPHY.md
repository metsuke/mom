# Visión y Doctrina: AUTHOR-W3C (W3C Bibliographic Corpus)

> **Proclamación Doctrinal:** AUTHOR-W3C es el nodo autor que agrupa el corpus de recomendaciones, estándares y notas técnicas del World Wide Web Consortium (W3C), sirviendo de base epistemológica para la accesibilidad, semántica y arquitectura web en MetsuOS.

---

## 🏛️ Principios Doctrinales

1. **Estructuración Recursiva de Estándares:** Las especificaciones del W3C (WCAG, WAI-ARIA, HTML, CSS) se desglosan de forma jerárquica y atómica en el árbol ESA (Obra → Capítulo/Principio → Pauta → Criterio → Técnica).
2. **Herencia No Mandatoria Seleccionable:** Los proyectos técnicos de MetsuOS que adopten recomendaciones del W3C solo extraerán los criterios y técnicas concretos referenciados, manteniendo limpia la compilación.
3. **Soporte de Contenido Libre / W3C Software and Document License:** Al ser especificaciones de difusión libre, el sistema permite la consulta navegable dual entre los resúmenes sintéticos atómicos y el texto literal de las pautas y técnicas.
